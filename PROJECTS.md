### 2. **Meezan (ميزان)** - Legal Translation Desktop App
- **Description:** Professional desktop application for legal document translation with specialized legal terminology database
- **Tech Stack:** PyQt6 · Python · SQLite
- **Features:**
  - Trilingual legal TMX (AR/EN/IT)
  - Functional-equivalence classification system
  - Legal terminology database with 10,000+ terms
  - Document comparison tools
- **Status:** 🟢 Stable Release
- **Repository:** [Meezan on GitHub](https://github.com/Dalal-Nsrallah/meezan)

### 3. **Taqleeb (تقليب)** - Combinatorial Arabic Haiku Machine
- **Description:** Generates one million unique Arabic haiku poems using combinatorial algorithms and classical poetry registers
- **Tech Stack:** JavaScript · AWS S3 · CloudFront · Node.js
- **Features:**
  - 1,000,000+ unique poem combinations per deck
  - 10 different Arabic poetic registers (from Al-Mutanabbi to contemporary poets)
  - Real-time poem generation
  - Downloadable collections
- **Status:** 🟢 Live at [taqleeb.com](https://taqleeb.com)
- **Demo:** [Try Taqleeb Now](https://taqleeb.com)

### 4. **ArabicCAT** - Professional CAT Tool
- **Description:** Web-based Computer-Assisted Translation tool with 22+ Arabic-specific quality assurance checks
- **Tech Stack:** HTML · CSS · JavaScript · WebSockets
- **Features:**
  - 22+ Arabic-specific QA checks
  - Real-time terminology lookup
  - Translation memory integration
  - Segment-based editing
  - Export to multiple formats (DOCX, XLIFF, TMX)
- **Status:** 🟡 Beta
- **QA Checks Include:**
  - Arabic diacritical marks validation
  - Gender and number agreement
  - Tashkeel consistency
  - Number formatting
  - Date format validation

- **Features:**

  - Offline-first architecture

  - Cross-platform desktop app (Windows, macOS, Linux)
  - Secure file deletion
- **Status:** 🟡 Development
- **Security:** Cryptography certified

### 6. **Arabic L10N Checker** - Localization Quality Assurance
- **Description:** Comprehensive localization checker with 44 quality checks across 10 categories
- **Tech Stack:** Python · Click CLI
- **Features:**
  - 44 localization checks
  - 10 quality categories:
    1. Character encoding
    2. Bidirectional text handling
    3. Number formatting
    4. Date/time formats
    5. Currency symbols
    6. Diacritical marks
    7. Punctuation consistency
    8. Untranslated strings
    9. Terminology compliance
    10. Context appropriateness
- **Status:** 🟢 Stable
- **Installation:** `pip install arabic-l10n-checker`
